# Fossils and Archeology Rebirth 0.0.1

The first Rebirth release starts a new version sequence for the Fabric port, maintained by **gemdYT**.

## Explore prehistory

- **64 prehistoric species**, including land animals, flyers and aquatic life.
- Fossil excavation, DNA analysis, culture and incubation, with animal feeding, taming, commands and riding.
- Species movement speeds, hunting, fleeing, defensive behavior, swimming and flight.
- **Five machines:** Analyzer, Culture Vat, Sifter, Worktable and Feeder, with hopper automation and optional energy support.
- Museum skeleton displays, a dinopedia, artifact restoration and ancient equipment.
- Fossil and amber deposits, prehistoric plants, volcanic terrain, ruins, temples, village buildings and the Anu encounter.

## Installation

Use **Minecraft 26.3**, **Java 25** and **Fabric Loader 0.19.5 or newer**.

- **Install kit:** download `fossils-archeology-rebirth-fabric-26.3-0.0.1-install-kit.zip`, extract it, and copy all six jars from its `mods/` folder into your Minecraft instance's `mods/` folder.
- **Standalone jar:** download `fossils-archeology-rebirth-fabric-26.3-0.0.1.jar` and install the five Fabric libraries below alongside it.

| Required library | Version |
| --- | --- |
| Fabric API | 0.161.0+26.3 |
| GeckoLib | 5.5.7 |
| TerraBlender | 26.3.0.0.9 |
| SmartBrainLib | 2.0.2 |
| Structure Pool API | 1.3.0+26.3-fabric |

Team Reborn Energy 5.0.0 is bundled inside the mod jar. Remove any previous Rebirth jar before installing this version, then restart Minecraft. The checksum file verifies the standalone jar and install kit.
